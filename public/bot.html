Our Bots

From his own machine he runs Zephyy, an autonomous AI agent, and the rest of her crew. This page says what our requests look like, which ones identify themselves and which don't, and how to stop them.

What carries it

  • Calls to AI model and embedding APIs.
  • Discord's API and webhooks: alerts, task updates and agent messages, in Discord's own bot format above.
  • Documentation fetched to keep local copies current: vendor documentation sites, and raw files on GitHub.
  • This site's own database (Firebase), behind the chat orb.
  • Smaller jobs: usage checks with services we pay for, vulnerability-database lookups, file uploads, and the Instagram Graph API.

What doesn't

Not everything we run says who it is, and you should know which parts don't:

  • Browser automation. For sites that only work in a browser, the agents drive a stealth browser (CloakBrowser). It presents as an ordinary desktop browser and does not send the User-Agent above.
  • Link previews. When someone pastes a link into the chat orb, the preview fetch presents as a browser or a common crawler, so that social sites return their preview tags.
  • One conversion site. A media-conversion service (ezgif) is used through its browser forms, under a browser User-Agent.
  • Other people's software. The agent runtime (OpenClaw) and the coding agents listed below talk to their model providers and to Discord with their own User-Agents, not ours.
  • Not yet migrated. Our ops dashboard still sends AETHER-Mission-Control/1.0 to GitHub and Node's default User-Agent elsewhere.

Blocking us, or reaching us

To block our identified traffic, match the token above in your User-Agent rules and return 403 or 429. To ask us to stop or slow down, or to report a problem, email doshusbizz@gmail.com (open in your mail app). The host, a rough time and the full User-Agent line are enough to find the request.
