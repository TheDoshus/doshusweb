Quality Pipeline

No script reaches production without passing all three gates. Quality isn't aspirational — it's structural.

🔍

qa-gate-v2.sh

Strict mode — syntax, error handling, env vars, shellcheck. Sha256-tracked registry. No registry entry = hasn't passed. Every change re-gates. Frozen in production.

→
📊

zephyy-audit.sh

RED blocks deploy. YELLOW to backlog. BLUE when in the file. Runs on every sweep cycle. False positives flagged, not blindly "fixed."

→
📐

coding-standards.md

Bash ≤ 10 lines for glue. Python for logic. Mandatory preflight checks. Every dependency declared up front. Fails loud or doesn't run.
